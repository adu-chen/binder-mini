# Changelog

## 0.1.0 - 2026-05-22

Initial governed MVP.

### Added

- ADU/APC governance baseline.
- Tauri 2 + React + TypeScript + Rust project skeleton.
- Workspace open and file list MVP.
- Editor open/save MVP for `.md` and `.txt`.
- Agent provider placeholder and observable local streaming response.
- Agent readonly tools: `read_file`, `list_files`, `search_files`.
- Diff Review MVP with `PendingDiff`, accept, reject, and expire behavior.
- GitHub open-source preparation files and CI baseline.
